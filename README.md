# edsancha.com

Personal site of Eduardo Diaz Sancha, built with [Jekyll](https://jekyllrb.com) and hosted on GitHub Pages. Feel free to download, fork and reuse the code.

## Local development

```sh
make install   # bundle install
make serve     # http://localhost:4000
make check     # build + link check (what CI runs)
```

Project conventions for people and coding agents are in [`CLAUDE.md`](CLAUDE.md). Adding a post: [`.claude/skills/new-post/SKILL.md`](.claude/skills/new-post/SKILL.md).
